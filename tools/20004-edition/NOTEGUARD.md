# 20004 NoteGuard — 临时笔记备份（初版）

注意：**不是实时自动保存或崩溃恢复系统**。这是一个只读的既有数据归档工具：备份当前 Notepad++ 配置、session.xml 和 backup 等目录中已经落盘的数据，复制到另一位置并按 SHA-256 校验。内存中尚未写入磁盘的内容无法通过该工具获取。

## Windows 用法

先在原版 Notepad++ 中保存重要内容，然后在 PowerShell 执行：

```powershell
py -3 tools/20004-edition/noteguard.py --dest "E:\Notepad-20004-SafetyBackups"
```

可以用 `--source` 指定另一个原版配置目录。建议目标是另外一个**物理磁盘**或可靠的备份设备，单纯换分区不等于硬盘故障保护。
